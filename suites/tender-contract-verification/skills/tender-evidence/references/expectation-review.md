# 主审查目标：合同是否低于有依据的预期

本套件优先回答：应当取得的交付、服务与保障，是否在合同中获得清晰、可执行的落实。一般文字一致性是辅助检查，不是最终目标。预期包括招标要求，也包括投标文件中适用于本项目的具体承诺和增量承诺；达到招标最低要求，不等于达到投标承诺形成的预期。

## 建立预期基准

按事项保留招标要求、投标响应、投标具体承诺及增量承诺、适用的澄清或变更。所有文档依据通过已有 factId 和 SourceRef 回溯，不能用归纳文本替换原文。

- 优先从投标承诺逐项向合同追踪：交付物、数量、人员、设备、型号参数、质量标准、期限、频次、免费范围、响应及到场时限、验收、质保、延寿、培训和服务保障。承诺可能出现在响应表、方案、技术表、承诺函或澄清中，不能只找“承诺”二字。
- 增量承诺独立建事实。招标至少三年、投标明确五年，五年需要单独核对；不能只用三年检验合同。
- 保留适用主体、项目/包件、对象、地域、阶段、起算点、费用、前置条件和例外。不机械选择全部材料中的最高数量、最短期限或最长质保期。
- 历史案例、资质介绍、产品理论能力、其他包件承诺和未经确认的愿景不自动作为本项目承诺。标记性质及判断依据，不因此丢掉其原文记录。
- “完全响应”只在其明确指向的要求可核查时关联基准，不能凭空补出数值。缺招标文件时仍核对投标中的明确承诺，不把整个预期审查停掉；不能据此宣称已覆盖招标预期。
- 矛盾版本、模糊指向或变更未经确认时，基准本身标记待确认。不能用合同后来写了较低标准，反向证明较高投标承诺已经被有效撤销。

这里的“预期基准”是比较依据，不自动等于已经确定的法律义务。承诺适用性、合同纳入及文件优先规则分别核对。

## 判断合同是否不及预期

对每个基准核对合同正文、附件、技术协议、引用纳入、优先顺序、排除条款及适用版本，区分明确写入、经核实的引用落实、部分落实、未找到、被削弱和无法判断。

重点检查：交付或投入减少；性能降低；费用转嫁；服务次数或期限减少；响应放慢；明确义务模糊化；新增前置条件或免责；将确定承诺改为可选择或另行协商；将承诺写入但缺少约定的保障。保障条款的差距必须有预期依据，不能把一般优化建议冒充原承诺。

输出区分三个层次，不从字面 Diff 自动生成结论：

1. **已证实低于预期**：适用的预期明确，比较条件一致，合同差距明确，并已核查有关纳入、例外和优先规则。说明少了什么、对实际取得的交付有什么影响。
2. **预期落实待确认**：合同条文下限较低、承诺未单列、写法含混或缺件，但尚不能排除引用落实或条件差异。保留疑点，不宣布承诺已经消失。
3. **达到预期或一般差异**：合同明确达到基准、经核实纳入承诺，或仅为文字、口径及可解释的细化差异。没有确定改善方向的冲突，不直接称为合同不及预期。

既有 verification.status 继续使用，不新增或冒充状态：weakened 可用于证据充分的削弱；partial 用于部分落实；insufficient_materials 用于材料不足；conflict 只表示冲突，必须另外解释是否朝不利于预期的方向变化；implemented/incorporated 仍须说明所对应的承诺。not_found 保持既有全合同与附件核查门控。疑点不得为了使用某状态而被删去。

## 各事项的结论内容

在 verification.reason 中依次写清下列内容，使用可读文字，不新增一套没有校验的隐含基准：

- 预期是什么：引用具体要求或承诺，指出是否属于投标增量；其 factId 应归属本事项。
- 合同如何约定：引用对应事实；未找到时明确核查范围。
- 差距与影响：仅说明有据的交付差距，或者说明为什么不能直接比较。
- 纳入及例外核查：说明相关条款和版本如何影响结论，证据挂在事项事实/上下文及 reviewedSources 中。
- 判断及不确定性：明确属于以上哪个层次；缺什么证据才能作进一步判断。

suggestion 独立说明如何把预期落实到合同，保留原承诺条件，不机械复制最严格数值；reviewNote 记录对反证、范围和纳入规则的实际复核。不得仅写“存在差异”“合同满足招标要求”就结束。

## 报告重点与覆盖

文档式报告上部优先呈现已证实的合同不及预期及预期落实待确认事项，明确区分两者。一般差异、内部矛盾和背景记录保留，但不计作已证实的预期损失。下部展示“预期依据原文 → 合同对应原文 → 差距及影响 → 解释性证据”，保留既有 Diff、真实关系连线及文档索引定位。

全量核验仍逐块登记 coverage、保留正常事项。优先审查投标承诺不等于只挑出风险；程序和背景材料可进入附录。历史快照的既有判断不得仅靠报告排序或标签批量改成“低于预期”，需按本方法重新实质核查后另存新快照。

## 边界例子

| 预期与合同 | 审查方向 |
|---|---|
| 招标三年；投标明确五年免费质保；合同三年 | 追踪额外两年，核对纳入/优先/例外；不能以达到招标三年结束审查。 |
| 投标两年质保加一年延寿；合同两年质保 | 查延寿内容、费用与适用规则，不改写为三年免费质保。 |
| 投标月度清洁；合同季度最低清洁 | 追踪月度承诺是否继续适用。两项下限可同时满足，不能只凭周期认定取消月度承诺。 |
| 投标通知后三天送货；合同三十天内供货并验收 | 先拆交货与验收节点，不认定自动延长二十七天。 |
| 投标本项目投入一百零八人；合同最低九十八人 | 追踪一百零八人的落实和纳入规则，不能把最低九十八人直接说成实际少十人。 |
